# PAGANI / HUAYRA BC — Macchina Volante

Pure HTML + CSS + JavaScript cinematic automotive website.

## Run
1. Put the 240 provided JPG frames into:
   `images/huayra-sequence/`
2. Name them exactly:
   `1.jpg` through `240.jpg`
3. Open `index.html` in a modern browser.

For best local testing, use a simple local server because browsers may restrict some local file behavior:
- VS Code Live Server, or
- `python -m http.server`

## Included
- 600vh sticky Canvas hero
- 240-frame scroll-controlled image sequence
- High-DPI canvas rendering
- object-fit-contain style drawing so the car is not cropped
- Loading screen with 0–100% progress
- Scroll-synchronized HUD phases
- Responsive mobile navigation
- Editorial Story / Design / Engineering / Specs / Craftsmanship / Features / CTA / Footer
- Reduced-motion accessibility handling
- No React, Next.js, Tailwind, Framer Motion, Lenis, or other framework dependencies
- No project showcase/card-grid style
